# 联网搜索技能（web-research）

你拥有 `web_search` 动作（参数 `query`，≤70 字）与 `web_fetch` 动作（参数 `url`）。
本技能指导你**何时以及如何用它们取代凭记忆猜测**。

## 何时搜索
- 不确定的 API / 库函数签名、参数、版本差异；
- 报错信息需要溯源（搜「错误文本 + 库名」）；
- 需要最新文档、第三方依赖用法、最佳实践或安全注意事项；
- 任务涉及外部事实（版本号、发布日期、兼容性矩阵）。

## 怎么搜
1. 把问题拆成 1-2 个精准关键词（避免长句），调用 `web_search`；
2. 从返回的标题/链接/摘要里挑最相关的 1-3 条；
3. 用 `web_fetch` 读取关键页面原文获取细节；
4. 用检索到的结论指导下一步编码，**在回复里标注信息来源链接**。

## 注意
- 搜索结果是辅助，最终以本地代码/测试为准；
- 一次搜索最多取 10 条（可在 web_search 配置里调），不要无限翻页。
